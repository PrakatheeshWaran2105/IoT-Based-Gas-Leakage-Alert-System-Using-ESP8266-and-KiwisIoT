# IoT-Based-Gas-Leakage-Alert-System-Using-ESP8266-and-KiwisIoT
An IoT-based gas leakage alert system using NodeMCU ESP8266 and MQ-2 Gas Sensor to detect gas levels, trigger buzzer and LED alerts, and monitor real-time sensor readings through the KiwisIoT platform.
IoT-Based Gas Leakage Alert System Using ESP8266 and KiwisIoT

About the Project

This project is an IoT-Based Gas Leakage Alert System developed using NodeMCU ESP8266 and an MQ-2 Gas Sensor. The sensor detects changes in surrounding gas levels, and the ESP8266 reads the sensor values to identify potential gas leakage conditions.

When the gas sensor reading crosses the configured threshold, the buzzer turns ON and the red LED indicates a gas alert. During normal conditions, the green LED remains ON, providing a simple local indication of the system status.

The project is integrated with the KiwisIoT Platform, where the ESP8266 sends gas sensor readings and alert status through Wi-Fi. The KiwisIoT dashboard displays real-time gas level readings and leakage alert status, allowing users to monitor the system remotely.
